# Introduction to SoupRune

**SoupRune** is a game framework built with **Rust** and the **Bevy** engine, designed specifically for creating **Deltarune** and **Undertale** fan games.

SoupRune leverages the high performance of Rust and the ECS (Entity Component System) architecture of Bevy, providing greater flexibility and extensibility.

## Core Features

*   **High Performance**: Written in Rust and natively compiled, say goodbye to lag.
*   **Modern Architecture**: Uses the Bevy engine, supporting data-driven development workflows.
*   **Powerful Scripting System**: Built-in **Mortar** scripting language, specifically designed for writing complex dialogue trees and narrative logic.
*   **Flexible Battle System**: Define battle choreography through RON configuration files, supporting complex bullet patterns.
*   **Map Editor Support**: Compatible with the Tiled map editor, making it easy to build game worlds.

## Target Audience

This documentation is primarily aimed at **Mod Creators** and **Level Designers**. You do not need to be proficient in the Rust programming language (though it helps); most game content can be implemented by editing configuration files (TOML, RON) and writing Mortar scripts.
