# 编排弹幕演出

> 涉及类型：`souprune_schema::danmaku`
>
> 涉及文件：`.performance.ron`

## 概述

SoupRune 的弹幕系统通过**弹幕演出文件** (`.performance.ron`) 定义。一个演出文件包含三个部分：

1. **原型 (Prototypes)** — 弹幕的外观、碰撞体、伤害等"预制体"定义
2. **行为 (Behaviors)** — 可复用的运动模式（直线、轨道、正弦波、自机狙等）
3. **时间线 (Timeline)** — 在何时、何处、以何种模式生成弹幕

演出文件由序列中的 `DanmakuPerformance` Chapter 触发：

```ron
DanmakuPerformance(
    performance: "states/battle/danmaku/demo_attack.performance.ron",
    translation: Some((0.0, 50.0)),  // 可选：生成偏移
)
```

## 演出文件结构

**类型**：`DanmakuPerformance`

```ron
(
    prototypes: { ... },   // HashMap<String, BulletPrototype>
    behaviors: { ... },    // HashMap<String, BulletBehavior>
    timeline: [ ... ],     // Vec<TimelineEvent>
)
```

## 弹幕原型 (BulletPrototype)

定义弹幕的视觉与碰撞属性。

```ron
"spear": (
    visual: "spear",                    // 精灵资源路径（在 textures/ 目录搜索）
    collider: BoxCollider(3.0, 12.0),   // 碰撞体
    damage: 2.0,                        // 伤害值（默认 1.0）
    lifetime: 4.0,                      // 存活时间/秒（默认 5.0）
    z_index: 15.0,                      // 渲染层级（默认 15.0）
    hit_behavior: Persistent,           // 命中行为
),
"pellet_orange": (
    visual: "flowey_pellet",
    frame_duration: 0.05,               // 帧动画间隔（目录引用时自动播放）
    collider: BoxCollider(6.0, 6.0),
    damage: 1.0,
    lifetime: 3.0,
    hit_behavior: DamageWhenStationary,  // 仅玩家静止时造成伤害
    color_tint: (hex: "#FCA600"),        // 颜色着色
),
```

### 字段一览

| 字段                  | 类型                  | 默认值                   | 说明                        |
|---------------------|---------------------|-----------------------|---------------------------|
| `visual`            | `String`            | `""`                  | 精灵路径。文件名 = 静态图片；目录名 = 帧动画 |
| `collider`          | `ColliderShape`     | `CircleCollider(4.0)` | 碰撞判定形状                    |
| `damage`            | `f32`               | `1.0`                 | 碰撞伤害                      |
| `lifetime`          | `f32`               | `5.0`                 | 存活秒数（超时自动销毁）              |
| `z_index`           | `f32`               | `15.0`                | Z 轴渲染顺序                   |
| `scale`             | `f32`               | `1.0`                 | 缩放倍率                      |
| `rotation`          | `f32`               | `0.0`                 | 初始旋转（弧度）                  |
| `hit_behavior`      | `HitBehaviorPreset` | `Default`             | 命中后的行为策略                  |
| `color_tint`        | `ColorTint`         | 无着色                   | 颜色叠加                      |
| `flip_x` / `flip_y` | `bool`              | `false`               | 水平/垂直翻转                   |
| `frame_duration`    | `Option<f32>`       | `None`                | 帧动画播放间隔                   |

### 碰撞体形状 (ColliderShape)

```ron
CircleCollider(4.0)         // 圆形（半径）
BoxCollider(3.0, 12.0)      // 矩形（半宽，半高）
```

### 命中行为 (HitBehaviorPreset)

| 值                      | 说明                   |
|------------------------|----------------------|
| `Default`              | 命中后消失，造成标准伤害         |
| `Persistent`           | 命中后不消失（如长矛、墙壁）       |
| `DamageWhenMoving`     | 仅玩家**移动时**造成伤害（蓝色弹幕） |
| `DamageWhenStationary` | 仅玩家**静止时**造成伤害（橙色弹幕） |
| `Custom { ... }`       | 完全自定义命中规则            |

```ron
// 自定义命中行为
hit_behavior: Custom(
    despawn_on_hit: true,
    damage_on_player_moving: true,
    damage_on_player_stationary: false,
    invincibility_duration: 0.5,
),
```

### 颜色着色 (ColorTint)

```ron
color_tint: (hex: "#FCA600"),            // 十六进制（支持 #RGB, #ARGB, #RRGGBB, #AARRGGBB）
color_tint: (rgba: (1.0, 0.5, 0.0, 1.0)), // RGBA 浮点（0.0–1.0）
```

## 行为定义 (BulletBehavior)

行为定义弹幕的运动方式。可以在 `behaviors` 中定义为可复用的命名行为，也可以在时间线事件中内联定义。

**多个行为可以叠加到同一弹幕上。**

### 内置行为类型

#### Linear — 直线运动

```ron
Linear((
    dir: (1.0, 0.0),    // 方向向量（会归一化）（默认 (0.0, -1.0)）
    speed: 200.0,        // 速度（像素/秒）（默认 100.0）
))
```

#### Orbital — 轨道运动

```ron
Orbital((
    angular_velocity: 0.8,   // 角速度（弧度/秒）（默认 1.0）
    radial_velocity: -60.0,  // 径向速度，负值向内收缩（默认 0.0）
))
```

#### Sine — 正弦波运动

```ron
Sine((
    axis: (1.0, 0.0),    // 主运动方向（默认 (1.0, 0.0)）
    amplitude: 20.0,     // 振幅（像素）（默认 20.0）
    frequency: 2.0,      // 频率（次/秒）（默认 2.0）
    phase: 0.0,          // 初始相位（默认 0.0）
))
```

#### Aimed — 自机狙

```ron
Aimed((
    speed: 120.0,        // 追踪速度（默认 120.0）
    angle_offset: 0.0,   // 角度偏移（弧度）（默认 0.0）
))
```

#### Tween — 属性补间动画

```ron
Tween((
    target: Opacity,     // 动画目标属性
    duration: 2.0,       // 动画时长（秒）
    ease: QuadOut,       // 缓动函数
    range: (0.0, 1.0),   // 起始值 → 结束值
    delay: 0.0,          // 延迟启动（秒）
))
```

可动画的目标属性 (`DanmakuTweenTarget`)：`Opacity`、`Scale`、`ScaleX`、`ScaleY`、`PositionX`、`PositionY`、`Rotation`

#### Stationary — 静止

```ron
Stationary()
```

#### Custom — 自定义 WASM 行为

```ron
Custom(
    id: "spiral_homing",     // WASM 行为注册 ID
    props: {                 // 传递给 WASM 的参数
        "spiral_speed": 80.0,
        "homing_strength": 0.5,
    },
)
```

### Easing 缓动函数

`Linear`（默认）、`QuadIn`/`QuadOut`/`QuadInOut`、`CubicIn`/`CubicOut`/`CubicInOut`、`SineIn`/`SineOut`/`SineInOut`、
`CircularIn`/`CircularOut`/`CircularInOut`、`ExpoIn`/`ExpoOut`/`ExpoInOut`、`ElasticIn`/`ElasticOut`/`ElasticInOut`、
`BounceIn`/`BounceOut`/`BounceInOut`、`BackIn`/`BackOut`/`BackInOut`

## 时间线 (Timeline)

时间线定义弹幕的生成时机和模式。

```ron
(
    t: 1.5,                      // 时间（秒）——默认为相对时间（与上一事件的间隔）
    absolute: false,             // 设为 true 表示绝对时间（默认 false）
    spawn: "spear",              // 引用的原型 ID
    pattern: EdgeGenerator(...), // 生成模式
    offset: (0.0, 0.0),         // 生成位置偏移（默认 (0.0, 0.0)）
    apply: ["move_right", "fade_in"],  // 引用的命名行为 ID 列表
    behaviors: [ ... ],          // 内联行为定义（与 apply 叠加）
)
```

### 生成模式 (SpawnPattern)

#### Single — 生成单个弹幕（默认）

```ron
pattern: Single,
```

#### RingGenerator — 环形生成

```ron
pattern: RingGenerator(
    count: 12,           // 弹幕数量
    radius: 100.0,       // 环半径（默认 0.0 = 中心点）
    start_angle: 0.0,    // 起始角度（弧度）（默认 0.0）
),
```

#### LineGenerator — 线性排列生成

```ron
pattern: LineGenerator(
    count: 6,
    spacing: 22.5,                  // 间距（像素）（默认 20.0）
    direction: (0.0, 1.0),          // 排列方向（默认 (0.0, -1.0)）
),
```

#### EdgeGenerator — 从屏幕边缘生成

```ron
pattern: EdgeGenerator(
    count: 5,
    side: Left,           // Left / Right / Top / Bottom（默认 Left）
    spacing: 35.0,        // 间距（默认 30.0）
    margin: 250.0,        // 距边缘的距离（默认 200.0）
),
```

#### CustomGenerator — 自定义 WASM 生成器

```ron
pattern: CustomGenerator(
    id: "my_pattern",
    params: { "spread": 45.0 },
),
```

## 完整示例

以下是一个展示多种攻击模式的弹幕演出文件（来自 `example_mod`）：

```ron
#![enable(implicit_some)]
(
    prototypes: {
        "spear": (
            visual: "spear",
            collider: BoxCollider(3.0, 12.0),
            damage: 2.0,
            lifetime: 4.0,
            hit_behavior: Persistent,
        ),
        "pellet_orange": (
            visual: "flowey_pellet",
            frame_duration: 0.05,
            collider: BoxCollider(6.0, 6.0),
            damage: 1.0,
            lifetime: 3.0,
            hit_behavior: DamageWhenStationary,
            color_tint: (hex: "#FCA600"),
        ),
        "pellet_blue": (
            visual: "flowey_pellet",
            frame_duration: 0.05,
            collider: BoxCollider(6.0, 6.0),
            damage: 1.0,
            lifetime: 3.0,
            hit_behavior: DamageWhenMoving,
            color_tint: (hex: "#40FEFE"),
        ),
    },

    behaviors: {
        "move_right": Linear((dir: (1.0, 0.0), speed: 200.0)),
        "move_left": Linear((dir: (-1.0, 0.0), speed: 200.0)),
        "spiral_in": Orbital((angular_velocity: 0.8, radial_velocity: -60.0)),
        "aimed": Custom(id: "aimed_spear", props: { "speed": 180.0, "smoothness": 0.8 }),
        "fade_in": Tween((target: Opacity, duration: 2.0, ease: QuadOut, range: (0.0, 1.0))),
    },

    timeline: [
        // 从左侧发射长矛
        (t: 0.0, spawn: "spear",
         pattern: EdgeGenerator(count: 5, side: Left, spacing: 35.0, margin: 250.0),
         apply: ["move_right", "fade_in"]),

        // 1.5 秒后，橙色花弹环形扩散（静止受伤）
        (t: 1.5, spawn: "pellet_orange",
         pattern: RingGenerator(count: 12, radius: 100.0),
         apply: ["spiral_in", "fade_in"]),

        // 再 2 秒后，自机狙长矛
        (t: 2.0, spawn: "spear",
         pattern: LineGenerator(count: 3, spacing: 60.0, direction: (0.0, -1.0)),
         apply: ["aimed", "fade_in"]),

        // 蓝色花弹环形扩散（移动受伤）+ 内联缩放动画
        (t: 1.5, spawn: "pellet_blue",
         pattern: RingGenerator(count: 16, radius: 80.0, start_angle: 0.785),
         apply: ["spiral_in"],
         behaviors: [
             Tween((target: Scale, duration: 1.0, ease: QuadOut, range: (0.5, 1.0))),
         ]),
    ],
)
```

### 关键设计要点

- **时间是相对的**：默认情况下 `t` 表示距上一事件的秒数，而非绝对时间。设置 `absolute: true` 使用绝对计时。
- **行为可叠加**：`apply` 列表中的多个行为会同时作用于同一弹幕。例如 `["move_right", "fade_in"]` 表示弹幕既向右移动又逐渐显现。
- **内联与命名混用**：`apply` 引用命名行为，`behaviors` 内联定义一次性行为，两者叠加生效。
- **颜色弹幕**：橙色 (`DamageWhenStationary`) 和蓝色 (`DamageWhenMoving`) 是 Undertale 的经典机制，通过 `hit_behavior` 和
  `color_tint` 组合实现。
