# 战斗系统配置

> 涉及类型：`souprune_schema::battle`、`souprune_schema::enemy`、`souprune_schema::sequence`
>
> 涉及文件：`.battle_player.ron`、`.enemy.ron`、`.sequence.ron`

## 概述

SoupRune 的战斗系统完全由数据驱动。一场战斗的定义由三类 RON 配置文件组成：

- **战斗玩家配置** (`.battle_player.ron`) — 定义玩家在战斗中的外观、碰撞体和物理参数
- **敌人定义** (`.enemy.ron`) — 定义敌人的属性、可用的 ACT/MERCY 选项
- **序列资产** (`.sequence.ron`) — 编排整场战斗的流程：加载资源、生成 UI、执行弹幕、处理交互

这三者通过 **Sequencer**（序列执行器）串联：序列资产中的 Chapter（章节）按顺序执行，每个 Chapter 是一个原子操作。

## 战斗玩家配置

**类型**：`BattlePlayerConfig`（`souprune_schema::battle`）

**文件**：`states/battle/players/player.battle_player.ron`

```ron
#![enable(implicit_some)]
(
    sprite_path: "assets/textures/common/view/heart.png",
    color: Srgba((red: 1.0, green: 0.0, blue: 0.0, alpha: 1.0)),
    physics_collider: (
        shape: Circle(radius: 8.0),
        debug_z_offset: 10.0,
    ),
    damage_trigger: (
        shape: Box(half_size: (2.0, 2.0)),
        debug_z_offset: 10.0,
    ),
    z_position: 10.0,
    default_mode_id: "soul_red",
    speed: 150.0,
    focus_speed_ratio: 0.5,
    invincibility: (
        duration: 1.0,
        flash_interval: 0.1,
        normal_color: Srgba((red: 1.0, green: 0.0, blue: 0.0, alpha: 1.0)),
        flash_color: Srgba((red: 0.5, green: 0.0, blue: 0.0, alpha: 1.0)),
        damage_sound: "audios/sfx/hurtsound.wav",
    ),
)
```

### 字段说明

| 字段                  | 类型                          | 说明                         |
|---------------------|-----------------------------|----------------------------|
| `sprite_path`       | `String`                    | 玩家精灵的资源路径                  |
| `color`             | `BevyColor`                 | 精灵着色（Undertale 中红色灵魂为默认）   |
| `physics_collider`  | `ColliderConfig`            | 用于移动碰撞的碰撞体                 |
| `damage_trigger`    | `ColliderConfig`            | 用于受击判定的碰撞体（通常比物理碰撞体小）      |
| `z_position`        | `f32`                       | 渲染层级                       |
| `default_mode_id`   | `String`                    | 初始攻击模式 ID（如 `"soul_red"`）  |
| `speed`             | `f32`                       | 正常移动速度（像素/秒）               |
| `focus_speed_ratio` | `f32`                       | 聚焦（慢速移动）时的速度倍率，`0.0`–`1.0` |
| `default_box`       | `String`                    | 默认战斗框 ID，默认值 `"main"`      |
| `invincibility`     | `BattleInvincibilityConfig` | 受击后的无敌帧配置                  |

### 碰撞体形状

```ron
// 圆形
Circle(radius: 8.0)

// 矩形（半宽、半高）
Box(half_size: (2.0, 2.0))
```

**设计要点**：`physics_collider` 控制玩家能不能穿过障碍物；`damage_trigger` 控制判定范围。通常判定范围远小于物理碰撞体——这是
STG 游戏的标准设计。

## 敌人定义

**类型**：`EnemyDef`（`souprune_schema::enemy`）

**文件**：`data/enemies/<name>.enemy.ron`

```ron
(
    id: "dummy",
    locale: (name: "{{battle/ui:ENEMY_DUMMY}}", file: "enemies"),
    stats: (hp: 100, attack: 0, defense: 0),
    description: "A cotton heart and a button eye.",
    mortar_path: "battle/enemies/dummy.mortar",
    acts: [
        (label: "{{battle/ui:ACT_DUMMY_CHECK}}",
         sequence: "states/battle/common/narration.sequence.ron",
         param: "act_check"),
        (label: "{{battle/ui:ACT_DUMMY_TALK}}",
         sequence: "states/battle/common/narration.sequence.ron",
         param: "act_talk"),
        (label: "{{battle/ui:ACT_DUMMY_FLIRT}}",
         sequence: "states/battle/acts/dummy/flirt.sequence.ron"),
        (label: "{{battle/ui:ACT_DUMMY_HUG}}",
         sequence: "states/battle/common/narration.sequence.ron",
         param: "act_hug"),
    ],
    mercies: [
        (label: "{{battle/ui:MERCY_SPARE}}",
         sequence: "states/battle/mercy/spare.sequence.ron",
         param: "mercy_spare"),
        (label: "{{battle/ui:MERCY_FLEE}}",
         sequence: "states/battle/mercy/end.sequence.ron"),
    ],
)
```

### 字段说明

| 字段            | 类型                  | 说明                                   |
|---------------|---------------------|--------------------------------------|
| `id`          | `String`            | 唯一标识符，用于 FRE Fact 投射的命名空间            |
| `locale`      | `LocaleInfo`        | 本地化信息（`name` 支持 `{{file:KEY}}` 模板语法） |
| `stats`       | `CombatStats`       | `hp`、`attack`、`defense`              |
| `description` | `String`            | 敌人描述文本                               |
| `mortar_path` | `String`            | 关联的 Mortar 对话脚本路径                    |
| `acts`        | `Vec<ActionOption>` | ACT 菜单选项列表                           |
| `mercies`     | `Vec<ActionOption>` | MERCY 菜单选项列表                         |

### ActionOption

每个 ACT/MERCY 选项指向一个 `.sequence.ron` 文件，被选中时执行该序列：

```ron
(
    label: "{{battle/ui:ACT_DUMMY_CHECK}}",  // 显示文本（国际化 key）
    sequence: "states/battle/common/narration.sequence.ron",  // 要执行的序列
    param: "act_check",  // 传递给序列的参数（可选）
)
```

### Fact 投射

加载敌人后，其数据会自动投射到 FRE Fact 数据库中，供 View 表达式和 FRE 规则引用：

| Fact Key                                                 | 类型         | 来源              |
|----------------------------------------------------------|------------|-----------------|
| `{id}.name`                                              | String     | `locale.name`   |
| `{id}.hp` / `{id}.hp_max`                                | Int        | `stats.hp`      |
| `{id}.attack` / `{id}.defense`                           | Int        | `stats.*`       |
| `{id}.act_count`                                         | Int        | `acts.len()`    |
| `{id}.action_labels`                                     | StringList | ACT 标签列表        |
| `{id}.action_sequences`                                  | StringList | ACT 序列路径列表      |
| `{id}.action_params`                                     | StringList | ACT 参数列表        |
| `{id}.mercy_count`                                       | Int        | `mercies.len()` |
| `{id}.mercy_labels` / `mercy_sequences` / `mercy_params` | StringList | MERCY 数据        |

这意味着在 View 表达式中可以直接引用 `$dummy.hp`、`$dummy.action_labels` 等。

## 序列资产与战斗流程

**类型**：`SequenceAsset`（`souprune_schema::sequence`）

**文件**：`states/battle/chapters/<name>.sequence.ron`

序列资产是 SoupRune 中最核心的编排工具。它定义了一系列按顺序执行的 **Chapter**（章节），每个 Chapter 是一个原子操作。

### 基本结构

```ron
#![enable(implicit_some)]
(
    mode: "battle",          // 激活战斗相关的系统和输入处理
    rules_file: "...",       // 可选：关联的 FRE 规则文件
    exits: { ... },          // 可选：命名退出点
    chapters: [ ... ],       // 按顺序执行的 Chapter 列表
)
```

### 完整战斗流程示例

以下是 `example_mod` 中的战斗序列，展示了一场完整战斗的典型流程：

```ron
#![enable(implicit_some)]
(
    mode: "battle",
    chapters: [
        // 1. 设置相机缩放
        SetCamera(SetZoom(2.0)),

        // 2. 加载敌人定义（数据投射到 FRE Fact 数据库）
        LoadEnemies(enemies: [
            "data/enemies/dummy.enemy.ron",
            "data/enemies/test1.enemy.ron",
        ]),

        // 3. 生成战斗 UI，绑定敌人数据
        SpawnView(
            view_layout: "states/battle/view/undertale.view.ron",
            bindings: { "enemies": LocalLayer },
        ),

        // 4. 等待 View 的 FRE 规则加载完成
        AwaitFact(condition: "$view_rules_loaded == true", local: true),

        // 5. 触发开场旁白
        EmitFactEvent(event_id: "battle:show_intro"),

        // 6. 启用菜单交互
        SetViewFact(key: "interactable", value: Bool(true)),
        SetViewFact(key: "depth", value: Int(0)),
        SetViewFact(key: "button_selection", value: Int(0)),

        // 7. 等待玩家确认选择
        AwaitFact(condition: "$selection_confirmed == true"),
        SetViewFact(key: "selection_confirmed", value: Bool(false)),

        // 8. 执行玩家选择的行动序列
        RunSequence(path_fact: "pending_sequence"),

        // 9. 进入弹幕阶段
        SetViewFact(key: "interactable", value: Bool(false)),
        SetPlayer(Spawn(
            config_path: "states/battle/players/player.battle_player.ron",
            position: (0.0, -80.0),
        )),

        // 10. 战斗框动画
        TweenViewElement(
            selector: LocalName("BattleBox"),
            target: BoxSize(to: (130, "@current")),
            duration: 0.85,
            easing: QuadInOut,
            wait_for_completion: false,
        ),

        // 11. 播放弹幕
        DanmakuPerformance(
            performance: "states/battle/danmaku/demo_attack.performance.ron",
            translation: Some((0.0, 50.0)),
        ),

        Wait(10.0),
    ],
)
```

### 战斗相关的关键 Chapter 类型

| Chapter                                               | 用途                        |
|-------------------------------------------------------|---------------------------|
| `LoadEnemies { enemies }`                             | 加载 `.enemy.ron`，投射数据到 FRE |
| `SpawnView { view_layout, bindings }`                 | 生成战斗 UI                   |
| `SetPlayer(Spawn { config_path, position })`          | 生成战斗玩家                    |
| `SetPlayer(Despawn)`                                  | 移除战斗玩家                    |
| `DanmakuPerformance { performance, translation }`     | 播放弹幕演出                    |
| `AwaitFact { condition, local }`                      | 等待条件成立（阻塞）                |
| `SetViewFact { key, value }`                          | 设置 View 局部 Fact           |
| `EmitFactEvent { event_id, data }`                    | 触发 FRE 事件                 |
| `RunSequence { path, path_fact, params }`             | 执行子序列                     |
| `TweenViewElement { selector, target, ... }`          | View 元素补间动画               |
| `SplitBattleBox / MergeBattleBoxes`                   | 战斗框分裂/合并                  |
| `Wait(seconds)`                                       | 等待指定秒数                    |
| `Sequence([...])` / `Parallel([...])`                 | 串行/并行执行                   |
| `Conditional { condition, then_branch, else_branch }` | 条件分支                      |

### 数据流

```
.enemy.ron ──LoadEnemies──→ FRE FactDatabase
                                  ↓
                           $enemy_id.hp, $enemy_id.action_labels ...
                                  ↓
.view.ron ──SpawnView──→ View 表达式引用 Fact ──→ UI 渲染
                                  ↓
                    .fre.ron 规则响应输入事件
                                  ↓
                    SetLocalFact("pending_sequence", ...)
                                  ↓
          RunSequence(path_fact: "pending_sequence") ──→ 执行 ACT/MERCY 序列
```
