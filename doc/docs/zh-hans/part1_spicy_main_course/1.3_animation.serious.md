# Alight Motion 动画集成

> 涉及 crate：`bevy_alight_motion`
>
> 涉及文件：`.amproj`（ZIP 压缩包）、`alight_motion_config.ron`

## 概述

SoupRune 集成了 **Alight Motion**（一款移动端动画制作应用）作为视觉动画的生产管线。通过 `bevy_alight_motion` crate，开发者可以直接将 Alight Motion 项目文件 (`.amproj`) 导入游戏，系统会自动解析场景、图层、关键帧和特效，并使用自定义 **SDF（Signed Distance Field）渲染管线** 进行实时渲染。

这意味着：**动画制作在 Alight Motion 中完成，导出后直接在 Bevy 中播放**，无需手动转换。

### 工作流程

```
Alight Motion 制作动画
    ↓
导出 .amproj 项目文件
    ↓
放入 projects/<mod>/assets/ 目录
    ↓
Bevy 加载 → 自动解析 XML + 嵌入资源
    ↓
SDF 渲染 + 关键帧动画 + 特效
```

## .amproj 文件格式

`.amproj` 文件是 ZIP 压缩包，内含：

| 文件 | 说明 |
|------|------|
| `*.xml` | 场景定义文件（图层、关键帧、特效） |
| `*.png` / `*.jpg` | 嵌入的图片资源 |
| `*.ttf` / `*.otf` | 嵌入的字体文件 |

系统通过 `AmProject` 资源加载：

```rust
pub struct AmProject {
    pub scene: AmScene,
    pub images: HashMap<String, Handle<Image>>,
    pub fonts: HashMap<String, Handle<Font>>,
    pub embedded_images: HashMap<String, Vec<u8>>,
    pub embedded_fonts: HashMap<String, Vec<u8>>,
    pub validation_report: ValidationReport,
}
```

## 场景结构 (AmScene)

一个场景包含画布设置和图层列表：

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | `String` | 项目标题 |
| `width` / `height` | `u32` | 画布尺寸（默认 1280×1280） |
| `fps` | `u32` | 帧率（默认 60） |
| `total_time` | `u32` | 总时长（毫秒） |
| `bgcolor` | `String` | 背景色 `"#AARRGGBB"` |
| `layers` | `Vec<AmLayer>` | 图层列表 |

### 图层类型 (AmLayer)

| 类型 | 说明 |
|------|------|
| `Shape` | 矢量图形（矩形、圆形、路径）— SDF 渲染 |
| `Image` | 位图精灵 |
| `Text` | 文本（支持字体加载和度量） |
| `Nullobj` | 空节点，用于分组/控制 |
| `EmbedScene` | 嵌套预合成（Pre-composition） |
| `Audio` | 音频播放（音量可动画化） |
| `Camera` | 相机变换（FOV 可动画化） |
| `Bookmark` | 时间线标记（元数据） |

### 关键帧动画

每个图层的变换属性都支持关键帧动画：

```rust
pub struct AmTransform {
    pub location: AmAnimatedVec3,    // X, Y, Z 位置
    pub pivot: AmAnimatedVec2,       // 旋转/缩放锚点
    pub rotation: AmAnimatedFloat,   // 旋转角度
    pub scale: AmAnimatedVec2,       // 缩放
    pub opacity: AmAnimatedFloat,    // 透明度
}
```

关键帧结构：

```rust
pub struct AmKeyframe {
    pub time: f32,           // 归一化时间（0.0–1.0）
    pub value: String,       // 值（字符串形式，运行时解析）
    pub easing: Option<String>,  // 缓动函数
}
```

### 缓动类型

| 类型 | 说明 |
|------|------|
| `Linear` | 线性（默认） |
| `CubicBezier` | 贝塞尔曲线（4 控制点） |
| `Step` | 阶跃（无插值） |
| `Bounce` / `ReverseBounce` | 弹跳效果 |
| `Cyclic` | 周期振荡（衰减、偏移） |
| `Elastic` / `ElasticStep` | 弹性效果 |

## SDF 渲染管线

矢量图形（`Shape` 图层）通过自定义 SDF 着色器渲染，而非传统网格：

1. 图形的尺寸、形状参数作为 uniform 传入着色器
2. 片段着色器计算到图形边界的距离
3. 描边宽度在缩放动画中保持恒定（因为它是 uniform 而非网格属性）
4. 支持混合模式（multiply、screen、overlay 等）

```
SDF 着色器管线：
  Shape 参数 → uniform → sdf_shape.wgsl → SDF 距离计算 → 抗锯齿 → 像素输出
```

**基础半幅值**：AM 的基础图形为 100×100 像素，`BASE_HALF_EXTENT = 50.0`。

## 坐标系转换

Alight Motion 使用左上角原点，Bevy 使用中心原点：

```
AM 坐标: (am_x, am_y) — 左上角 (0, 0)
    ↓
Bevy 坐标: (am_x - canvas_w/2, canvas_h/2 - am_y) — 中心 (0, 0)
```

Y 轴方向翻转。

## 战斗中的 AM 动画

在战斗中，Alight Motion 动画可以作为弹幕攻击的替代方案——用动画工具制作弹幕，而非手写 `.performance.ron`。

### 配置文件 (alight_motion_config.ron)

```ron
(
    scale: 2.0,                    // 尺寸倍率
    offset: (0.0, 0.0),           // 位置偏移
    bullet_pattern: "^#B",        // 正则：以 "#B" 开头的图层视为弹幕
    battle_box_pattern: "^#C",    // 正则：以 "#C" 开头的图层视为战斗框
    hidden_pattern: "^#B",        // 正则：隐藏的图层（弹幕使用碰撞体而非视觉）
    bullet_damage: 1.0,           // 弹幕伤害
    collision_scale: 0.05,        // 碰撞体缩放因子
)
```

### 命名约定

在 Alight Motion 中，通过图层命名来标记特殊行为：

| 前缀 | 含义 |
|------|------|
| `#B` | 弹幕图层（生成碰撞体，对玩家造成伤害） |
| `#C` | 战斗框图层（定义玩家可移动区域） |

`collision_scale` 通常很小（如 `0.05`），因为 AM 导出的图形有大量透明边距。

### 使用方式

在序列中通过 Chapter 加载 AM 动画：

```ron
// 在 .sequence.ron 中
AmPerformance(
    project: "states/battle/demo_turn.amproj",
    config: "states/battle/alight_motion_config.ron",
)
```

## 播放控制

运行时通过 `AmPlayback` 资源控制动画：

| 字段 | 类型 | 说明 |
|------|------|------|
| `current_time_ms` | `f32` | 当前播放位置（毫秒） |
| `total_time_ms` | `f32` | 总时长 |
| `playing` | `bool` | 是否播放 |
| `speed` | `f32` | 速度倍率（1.0 = 正常） |
| `looping` | `bool` | 是否循环 |

## 系统架构

```
AmProject 加载
    ↓
[Lifecycle] 为每个图层生成 Entity + AmAnimated 组件
    ↓
每帧：
  [advance_playback_system]     → 递增全局时间
  [animate_transform_system]    → 插值位置/旋转/缩放
  [animate_opacity_system]      → 插值透明度
  [animate_size_system]         → 插值尺寸
  [animate_sdf_*_systems]       → SDF 特有属性（拉伸、重复等）
  [animate_unified_effect_system] → 后期特效
  [manage_layer_lifecycle_system] → 图层可见性（入/出时间）
```

## 与纯 RON 弹幕的对比

| 维度 | `.performance.ron` | `.amproj` |
|------|-------------------|-----------|
| 制作工具 | 文本编辑器 | Alight Motion（可视化） |
| 精确控制 | ✓ 精确到像素和帧 | ✓ 可视化关键帧编辑 |
| 学习曲线 | 需要理解 RON 语法 | 需要会用 Alight Motion |
| 适用场景 | 程序化弹幕、规律性模式 | 精心设计的视觉演出、复杂动画 |
| 文件大小 | 极小（纯文本） | 较大（含嵌入资源） |
| 热重载 | ✓ | ✓ |

两种方式可以在同一场战斗中混用。
