# SoupRune 官方文档

**SoupRune** 是一个专门用于制作 **Undertale** 和 **Deltarune** 同人游戏的游戏框架。

本文档旨在为不同背景的开发者（策划、美术、程序员）提供完整的开发指南。

---

## 章节阅读指南

为了帮助不同背景的开发者快速上手，我们提供了以下阅读路径建议：

### 1. 入门开发者 / 策划 (无需编程)

如果您希望快速制作一场战斗或一个小游戏，且不希望涉及复杂的代码编写：

* 请从 **[Part 0: 环境配置与入门]** 开始。
* 重点阅读 **[Part 1: 战斗系统开发]**。通过修改 RON 配置文件，您即可完成战斗逻辑的构建。

### 2. 美术 / 编剧 (侧重表现)

如果您主要负责游戏的视觉表现和剧情演出：

* 完成 **[Part 0]** 的基础设置。
* 可以直接进入 **[Part 2: 世界场景与叙事]** 学习地图和剧本制作。
* 查阅 **[Part 1.3: 动画导入]** 了解如何导入动画资源。
* 深入阅读 **[Part 2.2: Mortar 脚本]** 掌握演出控制。

### 3. 程序员 / 框架开发者 (侧重逻辑)

如果您熟悉 Rust 或 C#，希望进行深度定制或开发复杂逻辑：

* 浏览 **[Part 0]** 快速配置环境。
* 根据需求查阅 **[Part 1-3]** 了解框架的数据驱动结构。
* 重点研读 **[Part 4: 高级脚本与底层开发]**，深入理解 ECS 架构与脚本系统。

---

## 快速导航

### Part 0: 环境配置与入门

**目标读者**：所有开发者

本章节介绍如何安装 SoupRune 框架，配置开发环境，并运行示例项目。

* **0.1 环境搭建**：安装必要的依赖和工具。
* **0.2 快速开始**：运行 Hello World 项目。

---

### Part 1: 战斗系统开发

**目标读者**：策划、战斗设计师

本章节详细讲解如何通过配置文件（RON）构建战斗系统，无需编写代码即可实现复杂的 Boss 战。

* **1.1 配置文件详解**：定义敌人属性、数值和基本行为。
* **1.2 弹幕编排**：使用时间轴和序列定义弹幕模式。
* **1.3 动画导入**：集成 Alight Motion 制作的动画资源。
* **1.4 交互逻辑**：编写 ACT 命令和文本反馈。

---

### Part 2: 世界场景与叙事

**目标读者**：关卡设计师、编剧

本章节介绍如何构建游戏世界，包括地图设计和剧情脚本编写。

* **2.1 地图制作**：使用 Tiled 编辑器绘制地图并导入框架。
* **2.2 Mortar 脚本**：SoupRune 专用的剧本语言教程，用于控制对话和剧情流。
* **2.3 NPC 与交互**：设置 NPC 行为和交互事件。

---

### Part 3: 视听与美化

**目标读者**：UI 设计师、音效师

本章节涵盖游戏界面的定制和音画表现的增强。

* **3.1 UI 定制**：修改界面皮肤、字体和布局。
* **3.2 音频管理**：配置背景音乐（BGM）和音效（SFX），实现动态混音。
* **3.3 视觉特效**：应用 Shader 和后期处理效果。

---

### Part 4: 高级脚本与底层开发

**目标读者**：程序员

本章节面向有编程基础的开发者，介绍如何使用 C# 或 Rust 扩展框架功能，以及 ECS 架构的深入解析。

* **4.1 语言选择**：C#、Haxe 与 Rust 的对比与选择。
* **4.2 逻辑编程**：脚本生命周期、组件系统与游戏逻辑实现。
* **4.3 框架扩展**：编写 Native 插件和底层模块。
