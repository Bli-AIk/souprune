# 项目简介

> ⚠️ SoupRune 处于早期开发阶段，API 和文件格式可能随时变更，不保证向后兼容。

## SoupRune 是什么

SoupRune 是一个基于 **Rust** 和 **Bevy 引擎** 构建的游戏框架，专门用于制作 Undertale / Deltarune 风格的同人游戏。它不是一个通用游戏引擎——它预设了 UT/DR 类游戏的核心玩法结构（回合制战斗、弹幕躲避、Overworld 探索、对话系统），让开发者专注于内容创作而非底层实现。

### 核心特点

- **数据驱动**：游戏逻辑通过 RON 配置文件、Mortar 脚本和 FRE 规则定义，不需要写 Rust 代码即可制作完整游戏
- **模块化**：游戏内容以 Mod 为单位组织，每个 Mod 是独立的资源+逻辑包
- **可扩展**：支持 WASM 组件模型（wasm32-wasip2）编写自定义行为，未来还将支持 C# 和 Haxe
- **Preset 复用**：`undertale_preset` 提供了完整的 UT 风格基础行为集，新项目可直接依赖

## 架构概览

### Workspace 结构

```
souprune/
├── crates/
│   ├── souprune/               # 主框架 crate
│   │   ├── src/core/           # 核心系统
│   │   └── src/app_state/      # 应用状态（Menu, Overworld, Battle）
│   ├── souprune_schema/        # RON 配置的类型定义
│   ├── souprune_api/           # WIT 接口定义（WASM 组件模型）
│   ├── souprune_sdk/           # Rust WASM guest SDK
│   ├── bevy_fact_rule_event/   # FRE 规则系统
│   ├── bevy_mortar_bond/       # Mortar 脚本语言绑定
│   ├── bevy_alight_motion/     # Alight Motion 动画导入
│   └── bevy_ecs_typewriter/    # 打字机文本效果
├── projects/                   # Mod 项目目录
│   ├── config.toml             # 当前活动项目配置
```

### 数据驱动哲学

SoupRune 的设计哲学是"**代码定义能力，数据定义内容**"：

```
Rust 代码（souprune 框架）
    ↓ 提供系统能力
RON 配置（.enemy.ron, .performance.ron, .sequence.ron）
    ↓ 定义游戏结构
FRE 规则（.fre.ron）
    ↓ 定义交互逻辑
Mortar 脚本（.mortar）
    ↓ 定义对话和演出
WASM 模块（.wasm）
    ↓ 定义自定义行为
```

对于大多数 UT/DR 同人项目，只需要使用配置文件和脚本就能完成全部内容——不需要触碰 Rust 代码。

## 项目结构

### `projects/config.toml` — 全局配置

```toml
[project]
mod_name = "example_mod"     # 当前活动的 Mod 名称
language = "en-US"           # 游戏语言

[window]
resolution_scale = 4         # 窗口缩放倍率
```

### `mod.toml` — Mod 配置

每个 Mod 目录下的 `mod.toml` 定义了该 Mod 的元数据和入口配置：

```toml
name = "example_mod"
version = "0.1.0"
authors = ["Your Name"]
description = "An example mod for SoupRune."

[resources]
textures = "assets/textures"
audios = "assets/audios"

[dependencies]
undertale_preset = "0.1.0"       # 依赖 UT Preset

[mod_library]
wasm = "mod_example.wasm"        # WASM 行为模块（可选）

[game]
global_rules = "global.fre.ron"
initial_sequence_path = "states/overworld/entry.sequence.ron"
initial_battle_path = "states/battle/chapters/demo.sequence.ron"
player_behavior_path = "states/overworld/players/player_behavior.ron"
input_config_path = "config/input.ron"
states_config = "config/states.ron"
```

关键字段：
- `dependencies`：声明依赖的其他 Mod（如 `undertale_preset`），被依赖 Mod 的资源会被合并加载
- `initial_sequence_path`：游戏启动后执行的第一个序列文件
- `initial_battle_path`：战斗模式的入口序列
- `entry_point`：设为 `false` 表示这是库 Mod（如 `undertale_preset`），不能独立运行

### Mod 目录布局

```
example_mod/
├── mod.toml                    # Mod 配置
├── assets/
│   ├── textures/               # 图片资源
│   └── audios/                 # 音频资源
├── config/
│   ├── input.ron               # 输入映射配置
│   └── states.ron              # 状态机配置
├── states/
│   ├── battle/
│   │   ├── chapters/           # 战斗序列
│   │   ├── enemies/            # 敌人定义
│   │   ├── performances/       # 弹幕演出
│   │   ├── rules/              # 战斗 FRE 规则
│   │   └── view/               # 战斗 UI 布局
│   └── overworld/
│       ├── maps/               # Tiled 地图
│       └── entry.sequence.ron  # 入口序列
└── global.fre.ron              # 全局 FRE 规则
```
