# 快速开始

> 前置条件：已完成 [[0.2_setup|环境配置]]，能够成功编译和运行 SoupRune。

## 运行示例项目

确保已安装示例 Mod（`./setup_mods.sh`），然后：

```bash
# 运行 example_mod（完整示例，含 Overworld + Battle）
cargo run -p souprune
```

默认配置（`projects/config.toml`）已指向 `example_mod`。如果要切换到其他示例：

```bash
# 编辑 projects/config.toml
[project]
mod_name = "example_battle_mod"   # 纯战斗示例
```

### 示例项目差异

| 项目 | 内容 | 适合场景 |
|------|------|---------|
| `example_mod` | Overworld 探索 → 遭遇战斗 → 对话 | 了解完整游戏流程 |
| `example_battle_mod` | 直接进入战斗 | 专注战斗系统开发 |
| `example_am_mod` | AM 动画集成的战斗 | 学习 Alight Motion 用法 |

## Mod 配置详解

### `mod.toml` 关键字段

```toml
[game]
# 游戏启动后执行的第一个序列
initial_sequence_path = "states/overworld/entry.sequence.ron"

# 战斗模式入口（如果 Mod 支持直接进入战斗）
initial_battle_path = "states/battle/chapters/demo.sequence.ron"

# 全局 FRE 规则文件
global_rules = "global.fre.ron"

# 玩家行为配置（Overworld 移动、碰撞等）
player_behavior_path = "states/overworld/players/player_behavior.ron"

# 输入映射
input_config_path = "config/input.ron"

# 状态机配置（AppState 的转换规则）
states_config = "config/states.ron"
```

`initial_sequence_path` 是整个 Mod 的入口——Sequencer 在游戏启动后会加载并执行这个序列文件。序列中可以切换状态（`SwitchState`）、加载地图（`LoadMap`）、进入战斗等。

### 依赖系统

```toml
[dependencies]
undertale_preset = "0.1.0"
```

Mod 可以声明依赖其他 Mod。被依赖的 Mod 的资源会被合并加载——这意味着你可以直接使用 `undertale_preset` 中定义的 View 布局、FRE 规则和序列模板。

`undertale_preset` 是一个**库 Mod**（`entry_point = false`），提供了 UT 风格游戏的基础设施：
- 战斗 UI 布局（`states/battle/view/`）
- 菜单导航和交互规则（`states/battle/rules/`）
- 通用序列模板（`states/battle/common/`）
- 弹幕演出模板

## 第一次修改

### 修改敌人属性

打开 `projects/example_battle_mod/states/battle/enemies/` 下的 `.enemy.ron` 文件：

```ron
(
    id: "dummy",
    locale: {
        "en-US": (name: "Dummy"),
        "zh-Hans": (name: "假人"),
    },
    stats: (
        hp: 20,                    // ← 试试改成 100
        atk: 0,
        def: 0,
    ),
    acts: [
        (label: "Check", sequence: "...", param: "act_check"),
        (label: "Talk",  sequence: "...", param: "act_talk"),
    ],
    mercies: [
        (label: "Spare", sequence: "...", param: "spare"),
    ],
)
```

修改 `hp` 值后保存，重新运行即可看到效果。

### 修改弹幕

弹幕演出定义在 `.performance.ron` 文件中。尝试修改时间轴参数：

```ron
timeline: [
    (time: 0.0, actions: [
        Spawn(prototype: "base_bullet", amount: 5),
        //                                    ^ 改成 20 试试
    ]),
    (time: 1.0, actions: [
        Spawn(prototype: "base_bullet", amount: 5),
    ]),
],
```

更详细的弹幕系统说明参见 [[1.2_danmaku|1.2 弹幕编排]]。

### 修改 FRE 规则

FRE 规则定义在 `.fre.ron` 文件中。例如修改菜单导航规则中的按钮数量上限：

```ron
conditions: [
    "$interactable == true",
    "$depth == 'main'",
    "$button_selection < 3",     // ← 改成 < 5 支持更多按钮
],
```

FRE 规则系统的完整说明参见 [[1.4_act|1.4 ACT/MERCY 交互与 FRE 规则]]。

## 应用状态流转

SoupRune 使用 Bevy 的 `States` 管理应用状态。默认的状态流转：

```
AppSetup → Menu → Overworld ⇄ Battle
                      ↑
                      └── 通过 NPC 交互或脚本触发战斗
```

| 状态 | 说明 |
|------|------|
| `AppSetup` | 资源加载、Mod 初始化 |
| `Menu` | 主菜单 |
| `Overworld` | 探索模式（地图、NPC、交互） |
| `Battle` | 战斗模式（回合制 + 弹幕） |

状态之间的切换通过序列中的 `SwitchState` 章节或 FRE 规则中的 `SwitchState` 动作触发。
