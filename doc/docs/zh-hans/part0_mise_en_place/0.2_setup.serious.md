# 环境配置

> ⚠️ SoupRune 处于早期开发阶段，目前没有预编译的二进制文件，必须从源码编译。

## 系统依赖

### Linux

**Arch Linux / Manjaro：**

```bash
sudo pacman -S base-devel pkg-config libx11 alsa-lib systemd-libs \
    wayland libxkbcommon
```

**Ubuntu / Debian：**

```bash
sudo apt-get install -y g++ pkg-config libx11-dev libasound2-dev libudev-dev \
    libwayland-dev libxkbcommon-dev
```

### Windows

- Visual Studio Build Tools（C++ 工作负载）
- 或 MinGW-w64

### macOS

```bash
xcode-select --install
```

## 必需工具

### Rust 工具链

SoupRune 使用 Rust stable 工具链。安装：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

验证安装：

```bash
rustc --version     # 需要 1.86+
cargo --version
```

### Git

需要 Git 来克隆仓库和管理 submodule：

```bash
# Ubuntu/Debian
sudo apt-get install git

# macOS (已随 Xcode CLI Tools 安装)
git --version

# Windows: 从 https://git-scm.com/ 下载
```

### 代码编辑器（推荐）

| 编辑器 | 推荐插件 |
|--------|---------|
| VS Code | rust-analyzer, Even Better TOML |
| RustRover | 内置 Rust 支持 |
| Neovim | rust-analyzer (LSP) |

## 获取源码

```bash
# 克隆仓库
git clone https://github.com/Bli-AIk/souprune.git
cd souprune

# 初始化 Git submodule（bevy_fact_rule_event, bevy_mortar_bond 等）
git submodule update --init --recursive
```

> **注意**：submodule 包含了 FRE、Mortar、AM 等核心 crate 的源码。如果跳过这一步，编译会失败。

## 获取示例 Mod

示例 Mod 通过 Git worktree 管理，使用内置脚本安装：

```bash
# 查看可用的 Mod
./setup_mods.sh --list

# 安装所有示例 Mod
./setup_mods.sh

# 仅安装特定 Mod
./setup_mods.sh example_mod

# 更新已安装的 Mod
./setup_mods.sh --update
```

`mods.toml` 定义了可用的 Mod 及其对应的 Git 分支：

```toml
[repo]
url = "https://github.com/Bli-AIk/souprune_example_mods.git"

[mods.example_mod]
branch = "mod/example_mod"
path = "projects/example_mod"
description = "Full-featured example with overworld and battle"
```

## 编译与运行

### 首次编译

```bash
# 编译整个 workspace
cargo build --workspace
```

首次编译需要下载和编译所有依赖（包括 Bevy），可能需要较长时间（5-15 分钟，取决于机器配置）。后续增量编译会快得多。

### 运行

```bash
# 运行当前活动的 Mod（由 projects/config.toml 指定）
cargo run -p souprune

# 带调试功能运行（Inspector + 性能 HUD）
cargo run -p souprune --features debug
```

`--features debug` 会启用：
- `bevy-inspector-egui`：运行时 ECS 实体/组件检查器
- `iyes_perf_ui`：帧率和性能指标 HUD
- 额外的调试日志输出

### 切换活动项目

编辑 `projects/config.toml`：

```toml
[project]
mod_name = "example_battle_mod"   # 改为你想运行的 Mod 名称
```

### 测试

```bash
cargo test --workspace
```

### 格式化与检查

```bash
# 代码格式化
cargo fmt --all

# 静态检查
cargo clippy --workspace --all-targets -D warnings
```

## 常见问题

### `cargo` 命令找不到

确认 Rust 已安装且 `~/.cargo/bin` 在 PATH 中：

```bash
source "$HOME/.cargo/env"
```

### 编译时找不到系统库

Linux 上通常是缺少开发头文件。按照"系统依赖"部分安装所有包。

### 编译速度慢

- 确认使用 release profile 时加 `--release`（但开发时通常不需要）
- 可配置 `config.toml`（Cargo 级）启用并行编译和链接器优化
- 推荐使用 `mold`（Linux）或 `lld` 链接器加速链接阶段

### Submodule 相关错误

```bash
# 重置并重新初始化
git submodule deinit --all -f
git submodule update --init --recursive
```

### 窗口黑屏 / GPU 相关错误

- 确认显卡驱动是最新版本
- Wayland 用户：尝试设置环境变量 `WINIT_UNIX_BACKEND=x11` 回退到 X11
