# SoupRune 介绍

**SoupRune** 是一个基于 **Rust** 和 **Bevy** 引擎构建的游戏框架，专为创作 **Deltarune** 和 **Undertale** 风格的同人游戏而设计。

与传统的 Unitale 或 Create Your Frisk 不同，SoupRune 利用了 Rust 的高性能和 Bevy 的 ECS（实体组件系统）架构，提供了更高的灵活性和扩展性。

## 核心特性

*   **高性能**: 基于 Rust 编写，原生编译，告别卡顿。
*   **现代架构**: 使用 Bevy 引擎，支持数据驱动的开发流程。
*   **强大的脚本系统**: 内置 **Mortar** 脚本语言，专门用于编写复杂的对话树和剧情逻辑。
*   **灵活的战斗系统**: 通过 RON 配置文件定义战斗编排，支持复杂的弹幕模式。
*   **地图编辑器支持**: 兼容 Tiled 地图编辑器，轻松构建游戏世界。

## 适用人群

这份文档主要面向 **Mod 创作者** 和 **关卡设计师**。你不需要精通 Rust 编程语言（尽管那会有帮助），大部分游戏内容可以通过编辑配置文件（TOML, RON）和编写 Mortar 脚本来实现。
