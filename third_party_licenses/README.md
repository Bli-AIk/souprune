# Third-party license texts

This directory archives common license texts used by third-party crates that
SoupRune builds or distributes.

These files are reference copies for redistribution notices. They do not replace
the license, copyright, or NOTICE files kept in each upstream repository or
submodule. When packaging a release, use dependency metadata and upstream files
to decide which notices are required.

Add another license text here only when a distributed third-party dependency
actually requires it.
